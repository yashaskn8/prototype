# Milk Analyzer Cleaning Procedure

## Daily cleaning
1. Remove the milk sample cup after testing.
2. Run the approved clean-water rinse.
3. Run one cycle with the approved cleaning solution.
4. Follow with two clean-water rinse cycles.
5. Wipe the sampling tube and external surfaces with a lint-free cloth.

## Thermostat cup
Remove the cup only while the analyzer is idle. Inspect for residue or scale, clean it with approved solution and a soft non-abrasive swab, rinse with clean water, then seat it fully again.

## If readings are abnormal after cleaning
Confirm the thermostat cup is seated properly, the sampling tube is not bent, and there are no visible air bubbles. Run the verification sample. If the result still fails, create a service call and attach the latest reading and any displayed error.
