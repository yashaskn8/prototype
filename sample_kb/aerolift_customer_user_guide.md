# Aerolift Customer User Guide

Use the equipment only within its approved purpose and rated load. Keep the travel area clear and do not operate if a safety device is damaged or bypassed.

If a problem occurs, stop operation safely, note the asset code and any displayed message, then use the customer support assistant for approved checks. If the documented guidance does not solve the problem, create a service call from the same interaction so the technician receives the troubleshooting history.
