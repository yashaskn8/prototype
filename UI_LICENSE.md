# UI source and license

The Servy-style Django pages in this prototype are original templates built to match the visual language of the supplied screenshots: purple navigation, operational tables, dashboard cards and knowledge-document tiles.

The component/layout foundation uses **Bootstrap 5.1.1**, bundled locally under `static/vendor/bootstrap/` so the prototype does not depend on a CDN or internet connection at runtime. Bootstrap is MIT licensed; its copyright/license header is retained in the bundled files.

The interface was designed using the same kind of free admin-dashboard patterns available from large template catalogues such as ThemeWagon, while avoiding redistribution of paid/proprietary template code. Product-specific styling is contained in `static/core/css/servy.css`.

No font files are bundled or redistributed.
